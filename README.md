Execute npm install to install all dependencies.

Use ng serve --o to launch the project.

Use ng test to run all tests.

Docker

I used Docker Desktop app and I installed wsl 2.

Run the following commands.

Create docker image -> docker build -t heroes-challenge .

Create and launch container -> docker run -d -p 3000:30 --name heroes-challenge heroes-challenge

See project in http://localhost:3000/
